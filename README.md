# Krankenhaus

Ein Prototyp für eine realistische Krankenhaus-Simulation als Ergänzung zum Leitstellen-Verbund.

## Aktueller Stand

- React/Vite/TypeScript-Grundlage
- Krankenhaus-Dashboard
- Notaufnahme mit Patientenliste
- Triage-Prioritäten
- Patientenakte
- Bettenbelegung
- Behandlungsaktionen als Simulations-UI
- Abteilungsstatus
- Ereignis-/Leitstellen-Log
- Grundlage für spätere Multiplayer- und Serverlogik

## Ziel

Das Projekt soll zu einem eigenständigen Krankenhaus-Spiel ausgebaut werden, in dem mehrere Spieler ein Krankenhaus betreiben können. Patienten werden unter anderem aus dem Leitstellen-Verbund durch Rettungsmittel eingeliefert und anschließend im Krankenhaus übernommen, untersucht, behandelt, stationär aufgenommen, operiert oder weiterverlegt.

Der aktuelle Stand ist bewusst ein kleiner spielbarer Frontend-Prototyp und noch kein vollständiges Multiplayer-Krankenhaus.
